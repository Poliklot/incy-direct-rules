Личное остаётся у вас

Модуль добавляет только Direct-правила. Ваш профиль, DNS и личные IP не загружаются в GitHub и не заменяются публичным профилем.

Без скриптов, MITM, сертификатов, подмены сайтов и IP-списков.

Подключить к своему профилю

  1. Сохраните рабочий профиль

    Оставьте его выбранным в INCY. Личные IP и остальные настройки остаются в нём.

  2. Добавьте нужный модуль

    Кнопка «Добавить и включить» включает модуль. Или скопируйте URL и откройте «Туннель → Модули → Добавить».

  3. Примените и проверяйте

    Переподключите VPN. После новой сборки обновляйте модуль из его источника. Автообновление по расписанию здесь не обещается.

Direct означает обход VPN: сайты видят ваш исходный IP. Включайте только нужные блоки; это личный набор правил, не универсальная рекомендация.

Правила с объяснениями

Раскройте «Домены и комментарии» в нужном блоке. Исходники лежат в rules/direct/*.txt: один домен на строку, пояснение после #. Actions проверяет изменения и собирает модули.

В новом формате обычное имя и domain: становятся DOMAIN-SUFFIX — домен и его поддомены. full: становится DOMAIN — только точное имя. Регистр и написание исходных доменов сохраняются.

Если вы уже импортировали старый Poliklot Direct: ссылка profile.json больше не является способом подключения этого проекта. Вернитесь к своему сохранённому профилю и подключайте модули отдельно. Уже имеющиеся Direct-домены можно оставить до проверки: личные IP удалять не нужно.

Откат — выключить добавленный модуль и переподключить VPN. Ваш исходный профиль остаётся на месте.

Версия исходников: $published_at. Сборка и SHA-256 модулей, исходные доменные записи, GitHub Actions.

Импорт по URL и ручное обновление проверены на тестовом модуле в INCY 2.6.2 на macOS (Apple-версия). Реальная маршрутизация и другие версии клиента требуют отдельной проверки. Неофициальный проект, не связан с командой INCY. Без аналитики и внешних ресурсов.
